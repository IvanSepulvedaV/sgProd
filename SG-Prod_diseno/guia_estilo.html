Guía de estilo SG-Prod

Sistema visual compartido por el Módulo 1 (Asignación) y el Módulo 2 (Calidad y KPIs). Pensado para jefes de línea con tableta o celular, en piso de planta.

Colores

Azul petróleo para la marca, amarillo hilo para la acción principal. Verde, ámbar y rojo se reservan solo para calidad.

Reglas para todo el equipo

  • Usar siempre las variables de theme.css, no colores sueltos.
  • Textos en español, con verbos claros: "Guardar", "Asignar", "Registrar pieza".
  • Cada estado lleva texto además de color.
  • Módulo 1 y Módulo 2 extienden base.html y reutilizan sg-card, sg-btn, sg-badge y sg-table.
